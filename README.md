Artificial Neural Network (ANN): Binary Classification Using the Make Moons Dataset

Objective: Build an Artificial Neural Network (ANN) to classify two classes of data using the Make Moons dataset generated with Scikit-learn.

Dataset: Make Moons Dataset

The dataset contains two interleaving crescent-shaped classes. It is useful for understanding how neural networks learn nonlinear decision boundaries.

Key Concepts:

- Synthetic dataset generation using "make_moons()"
- Data preprocessing and feature scaling
- Training and testing data splitting
- ANN architecture using Dense layers
- ReLU and sigmoid activation functions
- Binary cross-entropy loss
- Adam optimizer
- Model training and validation
- Binary classification evaluation
- Decision boundary visualization

Workflow:

1. Generate the Make Moons dataset.
2. Visualize the two classes using Matplotlib.
3. Split the dataset into training and testing sets.
4. Standardize the input features.
5. Build an ANN using TensorFlow and Keras.
6. Train the model using binary cross-entropy loss.
7. Evaluate the model using test accuracy and other classification metrics.
8. Visualize the learned decision boundary.

Technologies: Python, NumPy, Scikit-learn, TensorFlow, Keras, Matplotlib, Google Colab.

Learning Outcome: Understand how an ANN learns nonlinear patterns and classifies data points into two categories.
